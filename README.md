# Chamseddine Doula — Portfolio

A responsive, static portfolio for AI Engineering, Agentic AI, RAG, DevOps and Software Engineering.

## Deploy on GitHub Pages

1. Upload `index.html`, `styles.css` and `script.js` to the `main` branch of `chamseddinedoulaEsprit/portfolio`, replacing the existing files.
2. Under **Settings → Pages**, select **Deploy from a branch**, `main`, `/ (root)`.
3. Open `https://chamseddinedoulaesprit.github.io/portfolio/`.

The site runs without build tools or frameworks. Contact uses `mailto:` instead of an unconfigured form.

Project details are based on provided CV/project descriptions. Add public repository or demo URLs for Savour and Intelligent Delivery Platform when available.
